# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User-confirmed Go server, React, TypeScript and Vite. One embedded JSON file and one executable in production.

## Users
Hiring managers and technical interviewers assessing Vaidotas Petraitis's work during recruitment.

## Product Purpose
Make experience, project capabilities and engineering decisions easy to assess and provide direct contact links.

## Capabilities and Constraints
About, experience, four project detail pages and credentials. A single Portfolio Explorer provides navigation. No commands, horizontal tabs, category filter bar or intermediate project overview. See PLAN.md for the agreed contract.

## Evidence on Hand
Real content from the supplied CV, linked repositories and verified credential pages. The portrait and nine screenshots are served from web/public/images. No invented production metrics or project outcomes.

## Product Principles
- Keep professional and personal-project experience distinct.
- Use real source assets and readable text.
- Keep every project one navigation selection away.
- Preserve compact typography and a restrained frame.

## Accessibility & Inclusion
Native keyboard-accessible links and buttons, visible focus, reduced motion, descriptive images, responsive navigation and diagram equivalents.
